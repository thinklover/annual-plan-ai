# 年度業務計畫書 AI 填表系統 — 第一版規格

確認日期：2026-10-30

## 目標

依照長照機構評鑑基準 A1「業務計畫擬定與執行」的年度業務計畫書格式（壹～貳拾），
讓訪談人員依講稿進行現場訪談，把逐字稿貼進系統後，由 AI 自動填入計畫書各欄位，
AI 內容直接填入，人員抽查、修改後提交並匯出 Word。

## 技術與部署

- Vite + React + TypeScript，純靜態網站，部署於 GitHub Pages（公開 repo，GitHub Actions 自動發佈）。
- 不接資料庫：資料存在瀏覽器 localStorage，可存多份計畫書，提供匯出／匯入 JSON。
  資料存取集中在 `src/storage.ts`，日後改接 MySQL 只需替換該層。
- AI：Gemini API，由瀏覽器直接呼叫。API Key 與模型名稱在「設定」頁輸入，存於 localStorage，可一鍵清除。

## 訪談講稿

- 「年初計畫訪談」對應壹～拾陸；「年終成果訪談」對應拾柒～貳拾。
- 每題標註對應區塊／欄位；網頁上可勾選已問題目；可匯出 Word。
- 建議逐字稿以「訪談員：」「受訪者：」標示說話者。

## AI 功能

- 逐字稿：貼上文字（年初、年終各一份）。
- AI 全部填寫：依區塊分別呼叫，可並行；只提供「AI 全部填寫」，不再有各區塊單獨的 AI 按鈕（2026-10-30 調整）。每欄附逐字稿依據。
- 逐字稿沒提到 → 留白，由人工填寫。（2026-10-30 調整：取消「AI 推測空白欄位」）
- AI 修飾（文字欄位）：更正式／精簡／評鑑用語／自訂指令。
- AI 內容直接填入，不需逐欄確認；欄位旁以小標籤標示「逐字稿依據」，可點「依據」查看原句。
- 重跑 AI 不覆蓋人工修改過的欄位。（2026-10-30 調整：取消逐欄確認與全部確認按鈕）

## 提交與匯出

- 提交即鎖定為定稿，可解除鎖定；完成率未達 100% 時會先提醒。
- 定稿後可匯出 Word（標楷體、APA 風格）。
