# 居家評鑑資料系統 — 第一版規格

確認日期：2026-11-09（同日依補充資料修訂）

依「居家評鑑結構」三大結構、12 個項目建立評鑑資料頁。欄位依據「評鑑AI系統.xlsx」的表頭與截圖。
第一版完成 **11 個項目**，只有 3-4 服務滿意度調查顯示「建置中」，等提供問卷原始資料範例再做。

## 技術與定位

- 與年度業務計畫書**完全獨立**：同一個 repo、同一個 GitHub Pages 網站，但是另一個入口頁 `…/annual-plan-ai/eval/`（Vite 多頁入口）。兩邊互不連結，資料也分開存。
- 沿用現有 `index.css` 的樣式。
- **AI 只用在 3-1、3-3 的年度分析報告**（原因分析、改善措施的建議），其餘都是純表單輸入。AI 用 Gemini，API Key 與模型名稱和年度計畫書共用同一份設定（同網域 localStorage），評鑑頁也有「AI 設定」入口。
- 文字資料存在 localStorage，照片存在 IndexedDB。存取集中在儲存層，照片日後改放檔案伺服器時只需替換照片儲存層。
- 一個瀏覽器對應一個機構，不做登入。不提供 JSON 備份（2026-11-09 移除）。
- 人名都存完整姓名，資料只在本機瀏覽器。

## 共用規則

- **年份格式**：機構設定可選民國或西元，預設民國。所有畫面、年度選擇器、Word、Excel（含標題「114年度…」或「2025年度…」）都跟著切換。
- **日期**：輸入用日期選擇器，顯示為 `114.07.30` 或 `2025.07.30`。會議時間只填開始時間，例如 `18:30`。
- **年度**：各頁上方選年度，預設今年。
- **自動儲存**。刪除前要確認。
- **姓名下拉**：從 1-1 員工名冊取，也可以自由輸入。
- **年度總表**：照 xlsx 工作表表頭，一筆一列。有總表截圖的項目改照截圖。抬頭是機構全銜加「{年}年度○○總表」，匯出 Excel。
- **照片附檔**（2-2、2-3、3-2）：上傳時縮到長邊 1280px 的 JPEG，每筆最多 6 張，放進單筆 Word，每列 2 張。
- **下拉選項**都可以自行增加。

## 入口頁

- **機構設定**：全銜、設立地址、設立日期、願景、理念、使命，對應 xlsx「機構基本資料」A～F 欄；另有年份格式（民國／西元）。
- 12 個項目的卡片，不分「結構一／二／三」標題，3-4 顯示「建置中」。
- 機構設定以對話框開啟；尚未設定機構時，首頁顯示提示卡。

## 結構一 機構基本資料

### 1-1 基本資料建置與連動：員工名冊

員工名冊是全系統唯一的人員資料源。

**基本資料**（跨年度共用）：姓名、性別、職稱、長照小卡職別、到職日、離職日、到職體格檢查日期、失智症基礎訓練證號、身心障礙服務訓練證號、足部照護課程、BA17 特殊課程、CPR 有效日期。

**年度資料**（每人每年一份）：年度健康檢查日期，以及 6 類訓練時數總數：
專業課程、專業品質、專業倫理、專業法規、原住民族文化、多元族群文化敏感度及能力。

離職人員不刪除，在總表的備註欄顯示「離職」。

自動產生 4 張總表（Excel），格式照截圖：

| 總表 | 內容 |
|---|---|
| 新進人員體格檢查總表 | 當年度到職者：序號、姓名、性別、到職日、體檢日期、備註 |
| 特殊訓練課程總表（在職員工名冊） | 編號、姓名、職稱、到職日、長照小卡職別、身障、失智症、足部照護、BA17、CPR 有／無／到期日，附「統計至」日期 |
| 在職員工健康體檢總表 | 序號、姓名、性別、到職日、體檢日期、備註 |
| 在職員工訓練統計總表 | 編號、姓名、職稱、到職日、6 類時數、總計，附「統計截止」日期 |

### 1-2 服務量能

一年 12 列，一月一列：

- 手動填：案管個案數（含服務中、暫停服務）、申報人數、申報金額
- 自動算：居督男／女、照顧服務員男／女人數。依員工名冊，以每月月底在職人員、依職稱分類，可以手動修改
- 自動算（xlsx 表頭沒有，依補充資料新增）：新進居督、離職居督、新進照服員、離職照服員人數，依員工名冊的到職日、離職日

可以匯出 Excel。

## 結構二 經營管理效能

### 2-1 年度業務計畫

一份年度計畫分三個階段：

**年初計畫**
- 唯讀顯示機構設定裡的願景、理念、使命
- 前言
- **現況**（會寫進 Word）：
  - 上年度服務量：由 1-2 自動帶出 1～12 月的案管個案數、申報人數、申報金額，加上總計與平均
  - 人力數分布：由員工名冊自動算出上年度 12 月底在職人數，依居督、照服員和男、女分列
  - SWOT 四格
  - 平衡計分卡：財務、顧客、內部流程、學習成長，各填目標
- OKR：可以新增、刪除。每個 OKR 有目標，加上多個行動方案；每個行動方案有執行項目、量／質化指標、起訖月份
- 甘特圖：依行動方案的起訖月份自動產生

**年中檢討**：自動帶出 OKR 與行動方案，填執行成果、問題分析、修正計畫。

**年終成果**：
- **機構現況**，放在最前面、自動產生：當年度服務量能表，1～12 月各一列，加「總計」「平均」兩列。欄位是月、案管個案數、申報人數、申報金額、新進居督、離職居督、新進照服員、離職照服員。
- 自動帶出 OKR 與行動方案，填執行成果、問題分析、改善方案。

匯出 3 份 Word：年初計畫、年中檢討、年終成果。年終成果照截圖的「計畫／執行項目／量質化指標／成果」表格。

### 2-2 行政會議、2-3 團體督導會議

兩者共用同一套畫面，只換標題和資料分類。

| 欄位 | 說明 |
|---|---|
| 會議日期、會議時間、會議地點 | |
| 主席、紀錄人 | 員工姓名下拉。紀錄人就是 xlsx 的「會議紀錄」欄 |
| 參與人員 | 多選標籤 |
| 對象 | **只有團督有**，預設「居服員」 |
| 上次追蹤事項 | 新增時自動帶入同年度上一場的「下次追蹤事項」，可以修改 |
| 議題 | 不限數量的清單，每項有標題、討論內容、決議，可以新增、刪除、上下移動 |
| 下次追蹤事項 | |
| 會議照片 | 附檔 |

匯出：
- **單場 Word**：版面照會議紀錄列印截圖。抬頭、基本資料表、上次追蹤事項、（一）議題／討論／決議、下次追蹤事項、照片。
- **行政會議年度總表**：照 xlsx 表頭。議題、討論內容、決議三欄，多個議題在同一格用編號換行對應。附檔欄放照片張數。
- **團督年度總表**：照截圖，欄位是序、會議日期、會議時間、會議主題（各議題標題用「、」連接）、對象。

### 2-4 個別督導紀錄

欄位：個督日期、人員姓名、問題、人員回饋、改善方案及期限、主責居督。

- 機構只有一位居督：主責居督自動帶入員工名冊裡職稱為居督的人。
- 一位員工一年可以做多次個督：人員姓名下拉列出全部在職人員，今年還沒做過的排前面。
- 匯出單筆 Word。
- **年度總表**照截圖，欄位是序、姓名、到職日、個督日期。當年度在職的照服員都列出，還沒做個督的日期留白。做過多次的**全部列出**，只寫月／日，用「、」連接，例如 `3/10、6/18`。

## 結構三 專業照護效能與個案權益保障

### 3-1 意外或緊急事件、3-3 意見反映或申訴事件

**事件紀錄欄位**，照 xlsx 表頭：
- 3-1：發生日期、事件類型、事件說明、事發當下因應措施、事件追蹤或結案說明、主責居督說明、單位主管說明
- 3-3：發生日期、事件類型、意見反映或申訴者、事件說明、因應措施、事件追蹤或結案說明、主責居督說明、單位主管說明

**事件類型**下拉選單：
- 3-1：交通事故、照顧意外事件、性騷擾／性侵害、傳染病事件、其他
- 3-3：意見反映、申訴事件

**匯出**：
- 單筆事件 Word
- 年度總表 Excel，照表頭，一件一列
- **年度分析與改善報告 Word**，例如「114年度意外事件分析檢討」：
  - 類型統計表由系統自動算：類型、件數、占比、合計，3-1 另有「主要內容簡述」欄可以人工填
  - 原因分析、改善措施：按「AI 建議」，由 Gemini 參考當年度全部事件紀錄、類型統計、機構基本資料和服務量能，提出 **3～5 個關鍵要因**，每個要因附**具體可行的行動方案**，填入兩欄後人工可以修改

### 3-2 個案討論會議

| 欄位 | 說明 |
|---|---|
| 會議日期、會議時間、會議地點 | |
| 紀錄人 | xlsx 的「會議紀錄」欄 |
| 參與專業人員 | 清單，每人有姓名與專業類別。類別：護理、社工、個管人員、居督員、藥師、照管專員、職能治療師、物理治療師 |
| 個案現況摘要 | 含已提供服務及因應措施，個案存完整姓名 |
| 跨專業討論的問題 | |
| 與會專業人員建議之要點 | |
| 後續追蹤及結案說明 | |
| 附檔 | 照片 |

匯出：
- 單場 Word
- **年度總表**參考「跨專業討論會議總表」截圖，但不要會議主題，欄位是序、會議日期、會議時間、與會專業類別（自動彙整，用「、」連接）
